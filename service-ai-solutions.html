Frequently Asked Questions

How do you prevent the AI model from hallucinating?

We enforce strict JSON schema output modes, provide ground-truth context via internal documentation, and implement programmatic validation nodes that reject answers not conforming to known schemas.

Is our proprietary company data used to train public models?

No. When using commercial API tiers (OpenAI, Anthropic, Gemini), terms explicitly state that customer payload data is never used to train base models. We also offer private self-hosted open-source model options.

Why do you recommend n8n over Zapier or Make?

n8n can be self-hosted on your own private cloud VPS. This means unlimited workflow executions with zero per-task charges, complete data privacy within your firewall, and deeper customization with custom JavaScript code nodes.

What are the ongoing monthly costs for an AI automation system?

By routing tasks to modern high-efficiency models like Gemini 1.5 Flash or Claude 3.5 Haiku, monthly API token costs for hundreds of daily operations are typically under $15 to $30.
